About PhotoShare

Secure photo sharing with temporary access control

The Project

PhotoShare is a secure photo sharing platform where admins can organize photos into groups and sections, and grant temporary access to others.

Every access grant creates a 1-hour session that the admin can revoke at any time. Friends request access using a group code and password, and the admin approves or rejects.
